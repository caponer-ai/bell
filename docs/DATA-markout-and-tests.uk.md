## 1. Markout (токсичність флоу для LP) по годинах UTC

Метод (її): v3 Swap-логи пулів AAPL/USDG 0xaae0d815ee56e4092a5e5c2911e676fea50b2d6d і NVDA/USDG 0xd4eb21209c4d6093f80b5b84f5c45cc093ea14a3, блоки 52 982 039 - 64 768 972 (03.09 - 16.09.2026). Для свопу i ціна виходу = sqrtPriceX96 наступного свопу j у тому ж пулі з block_j ≥ block_i + 3 000 (300 с); цензура, якщо block_j > block_i + 36 000 (1 год): AAPL 388/125 485 (0.3%), NVDA 2 968/211 393 (1.4%). r = (sqrtP_i/sqrtP_j)² − 1; markout = r, якщо свопер купив акцію (amount1 < 0), інакше −r. Позитивний markout = PnL свопера = збиток LP. Час: 10 блоків/с, якір блок 64 768 972 = 16.09 19:45 UTC. CI95 = 1.96·σ/√N. Межі: ціна виходу включає імпакт наступного трейда; базлайн +0.1…+0.4 bps усюди (ймовірно мікроструктурний зсув), тому читати різницю між годинами, не абсолют; 9 буднів (3, 4, 8, 9, 10, 11, 14, 15, 16.09), 2 тикери, один пул на тикер. ## 3. П'ятнадцять тестів для Bell на MockVerifierProxy (Chainlink Local)

> Примітка 19.09.2026 (термінологія): слова OpenPrint і ClosePrint нижче це лексика policy v1. Чинний термін: **сесійна референсна ціна за політикою Bell** (OPEN-референс і CLOSE-референс, policy v2 «драбина»). Під v2 змінився і зміст двох кейсів: №4 і №11 писались під правило «найменший obs у вікні», якого більше немає (вибір іде по сходинках O + 30·i, замовчування дає UNRESOLVED, а не іншу ціну). Кейси лишені як є, щоб історія рішень читалась.

Пріоритет, якщо різати: 1, 2, 3, 4, 7, 8 (прямо відповідають знайденим ончейн-дефектам: 27/27 lock == settle = відсутність тестів 3/8; stale-прінт 2.7 год = відсутність тесту 7).

1. replay_same_report: verify() двічі тим самим звітом → другий виклик не змінює стан, подія не дублюється (або revert за дизайном); сетлмент двічі неможливий.
2. expired_expiresAt: expiresAt < block.timestamp → revert StaleReport; стан не змінено. Межа: верифаєр цього НЕ робить, Bell робить сам.
3. status2_obs_before_boundary: marketStatus 2, obs = межа − 120 с → у OpenPrint не кваліфікується; OpenPrint unset; без жодного obs ≥ межі за latency-бюджет → прапор degraded + fallback.
4. poster_late_11min_plus_backfill: перший сабміт о межа + 11 хв з obs = межа + 3 с; потім backfill obs = межа + 0 с → OpenPrint = межа + 0 с; вікно якорене до межі; сетлмент бере скоригований OpenPrint.
5. duplicate_same_second: два валідні звіти з однаковим obs і різним mid → обидва приймаються; tie-break задокументований (наприклад, менший lastSeenTimestampNs); повторний прогін ідентичний.
6. status0_unknown: marketStatus 0 в очікувану сесію → сесія НЕ відкривається, oracle unavailable, сетлмент заблоковано, подія-алерт.
7. halt_via_lastSeenNs: status 2, але obs − lastSeen/1e9 > поріг (наприклад, 60 с) → прапор stale, ціна не для сетлменту; свіжий звіт знімає прапор. Межа: поріг = параметр дизайну.
8. early_close_13ET: день з close 13:00 ET; status 2 до 13:00 ET, далі 5/3 → ClosePrint на межі 13:00 ET (17:00 UTC влітку / 18:00 взимку); сесія не тягнеться до 16:00 ET.
9. session_merge_gap: close дня N, ніч без жодного звіту, open дня N+1 → сесії роздільні; OpenPrint дня N+1 лише зі звітів obs ≥ межі дня N+1.
10. DST_transition: перехід США 01.11.2026 → open 13:30 → 14:30 UTC, без подвійної/пропущеної межі; монотонність не ламається. Межа: тестує календарну лібу Bell.
11. older_report_after_newer_in_window: прийнято obs = T+5, у вікні приходить obs = T+2 → приймається, OpenPrint = min; після закриття вікна той самий obs = T+2 → відхиляється, settled OpenPrint незмінний.
12. wrong_feedId: валідний звіт з feedId ≠ сконфігурованому → revert/ignore, стан незмінний.
13. bad_signature_configDigest: підписи іншого DON → revert на verify. Межа моку: MockVerifierProxy криптографію не перевіряє, справжня перевірка = інтеграційний тест на тестнеті з реальним VerifierProxy.
14. window_boundary_exact: obs = межа + N і obs = межа + N + 1 с → перший у вікні, другий поза; без off-by-one.
15. status4_overnight_conservative: marketStatus 4 поза сесією → не Regular; OpenPrint не ставиться; лише status 2 відкриває.
